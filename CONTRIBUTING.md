# Contributing to Helpdesk UI

Thank you for your interest in contributing to Helpdesk UI.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Install the project dependencies.
4. Create a new branch for your changes.
5. Make and test your changes.
6. Push your branch.
7. Open a pull request.

## Development Guidelines

- Keep changes focused and readable.
- Follow the existing React project structure.
- Use meaningful component and variable names.
- Avoid unnecessary dependencies.
- Test the application before submitting changes.
- Update documentation when your changes affect project usage.

## Pull Requests

When opening a pull request, please include:

- A short description of the change
- The reason for the change
- Any relevant screenshots for UI changes
- Testing details

## Issues

Before opening an issue, check whether a similar issue already exists.

For bugs, include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots or error messages when applicable

Thank you for contributing!
