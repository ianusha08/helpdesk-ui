# 🎧 Helpdesk UI

A modern helpdesk and support ticket management interface inspired by platforms like Linear and Zendesk. Built with React, TypeScript, and Tailwind CSS.

## ✨ Features

- 🎫 Ticket management
- 🔄 Real-time status & priority updates
- 🔍 Smart search and filtering
- 💬 Public replies & private comments
- 📊 Analytics dashboard
- 🏷️ Ticket properties management
- 🗑️ Delete confirmation dialogs
- 📱 Responsive UI

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- shadcn/ui
- React Query
- Recharts
- React Router
- Express.js

## 🚀 Run Locally

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
node index.js
```

Create a `.env` file:

```env
VITE_API_URL=http://localhost:3001/api/tickets
```
